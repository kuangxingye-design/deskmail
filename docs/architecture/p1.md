# DeskMail v0.1 架构定稿（P1）

> 状态：**定稿**（决策 D1/D2/D3 已由人确认）。对应 Proposal：#1。随空骨架 PR 合入；定稿即只读，后续变更新增文档、不覆盖本文件。
> 范围：P1 立主干。骨架代码在 `src/`，本文件是它的架构说明。

## 1. 已确认决策

| # | 决策 | 选择 | 依据摘要 |
| --- | --- | --- | --- |
| D1 | 技术栈 | **Electron + TypeScript**（域逻辑在主进程，ui 在渲染进程，单语言） | 原型复用、imapflow 生态、AI 协作与「人能讲清」成本最低；接受常驻内存 ~200MB、安装包 ~100MB |
| D2 | 全局快捷键 | **`Alt + \``（反引号）** | 单手可达、冲突少；注册失败启动即提示；可配置化留增量 |
| D3 | 远程图片策略 | **一律不加载**；内嵌 cid 图片仍显示、可复制 | 隐私与安静定位，追踪像素不生效。实现约束：CSP img-src 仅本机数据；渲染前必须经净化（#7 落地前禁止渲染真实邮件 HTML） |
| 附注1 | 服务器删除对账 | **以服务器为准**：UID 对账后本地移除（本地重要性随之丢弃） | 多端一致；个人自用可接受 |
| 附注2 | 同步策略 | **两阶段**：先取头（列表秒可用）→ 后台队列按序补正文；详情打开时该封未缓存则即时取 | 首启列表 <10s；正文单封上限 2MB 截断 |

## 2. 模块划分与依赖

```
ui（渲染进程：列表/详情/账号管理三视图 + 视图状态机）
 └─ inbox（收件箱用例：混排、筛选、未读聚合、打开即已读、重要性标记）
     ├─ mailstore（本地存储：持久化、查询、未读、游标、UID 对账）
     ├─ sync（同步引擎：调度、增量、200 封窗口、翻页）
     │    ├─ imap（协议适配：连接/认证/FETCH/STORE，per-provider 参数表）
     │    └─ content（邮件内容：MIME 解析、HTML 净化、文本提取、cid 图片关联）
     ├─ accounts（账号管理：CRUD、去重、默认名、连接测试；凭据经 shell 安全存储）
     └─ shell（平台壳：窗口/磨砂/置顶/热键/剪贴板/凭据存储 = PlatformServices 的平台实现）
```

**边界规则（骨架期焊死）**：核心域（imap/content/store/sync/accounts/inbox）不 import 壳层 API；平台能力一律经 `PlatformServices` 注入（`src/platform/types.ts`）。读路径：`imap FETCH → content 解析 → mailstore → inbox → ui`；副作用路径：`ui → inbox → 本地写 + 远端写（\Seen 异步）`。

## 3. 关键数据模型（`src/model/types.ts`）

| 实体 | 关键字段 | 说明 |
| --- | --- | --- |
| Account | id, provider(qq\|netease163\|netease162), email, alias, color, status(ok\|auth_failed\|sync_error), createdAt, lastSyncAt?, lastSyncError? | email 规范化小写唯一（去重）；凭据不在此对象，存 PlatformServices.credentials（key=accountId） |
| Message | id, accountId, imapUid, messageId?, senderName?, senderEmail, subject, receivedAt, isRead, importance(normal\|important\|critical), bodyText, bodyHtml?, inlineImageIds[] | (accountId, imapUid) 唯一；receivedAt=IMAP INTERNALDATE 用于混排；importance 纯本地 |
| InlineImage | id, messageId, cid?, contentType, size, data(bytes) | 复制时转 PNG；与 Message 一对多 |
| SyncState | accountId, lastSyncAt?, lastUid, uidValidity?, windowStartUid, status, lastError? | windowStartUid=滚动加载游标；uidValidity 变化触发全量重取 |
| CardState | visible, x, y, filterAccountId(string \| null，null = 全部账号), view(list\|detail\|manage), lastOpenMessageId? | 对应 Proposal「卡片」概念；位置与视图状态分开持久化 |

## 4. 风险清单（摘要）

| 风险 | 对策 | 验证 |
| --- | --- | --- |
| QQ/163/162 协议与授权差异（162 共用 imap.163.com 待实测；网易要求 ID 命令；QQ 风控） | per-provider 参数表 + 前置 ID 命令 + 失败明确指引 | 三类各 1 真实账号冒烟（#5） |
| HTML 渲染安全（脚本/远程资源） | 净化 + 沙箱渲染 + D3 远程图片不加载 | 恶意样例测试（#7） |
| 内嵌图片复制 PNG（GIF 转 PNG 丢动画） | 取存储字节直写剪贴板，不经渲染回读 | 真机粘贴验证（#11） |
| 磨砂玻璃跨版本/RDP 表现不一致 | WindowEffects 抽象 + acrylic 优先 + 兜底 | Win11 本机验证（#10） |
| 全局快捷键冲突/误触 | 组合键 Alt+`；注册失败启动提示 | 与占用应用共存测试（#10） |
| 凭据明文落盘 | 只进 DPAPI（Electron safeStorage） | 磁盘扫描无明文（#9） |
| 单账号失败阻塞全部 | 调度按账号隔离 + 指数退避 | 故障演练（#8） |
| UIDVALIDITY 变化 / 服务器删除残留 | 记录 uidValidity；UID 集合对账（附注1） | 单测 + 真实翻页（#8） |
| 首次全量同步慢 | 两阶段同步（附注2） | 首启列表 <10s（#8） |
| 超大邮件正文 | 单封 2MB 截断；附件 part 跳过 | 大邮件测试（#7/#8） |
